# Movie Application 

A Python-based movie application built as a class project.  
This project demonstrates object-oriented programming concepts and file handling in Python.

## Features
-  Manage a collection of movies
- Track customers and their rentals
-  Store data in text files (`Movies.txt`, `customer.txt`)
-  Command-line interface for interaction

## Tech Stack
- Python 3
- File I/O for persistent storage

## Project Structure
- MovieClass.py → Defines the Movie class and related logic
- MovieMain.py → Main program to run the application
- Movies.txt → Stores movie data
- customer.txt → Stores customer data
